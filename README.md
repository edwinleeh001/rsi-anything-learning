# RSI-Anything · Bilingual paper learning guide

Live website: https://edwinleeh001.github.io/rsi-anything-learning/

Twenty detailed English/Chinese chapters, independent speaker-note language, seven original paper figures, bilingual framework diagrams, three inspectable teaching activities, three short animations with English and Chinese narration (six MP4s), thirty glossary entries, twenty sourced discussion questions, chapter quizzes, and printable speaking notes.

Based on Cui et al., *RSI-Anything: Unlocking Recursive Self-Improvement with World Models*, arXiv:2610.13912v1. The authors' paper, original figures and font licenses retain attribution. This educational guide distinguishes reported results, synthetic teaching examples and research proposals. It does not claim to reproduce the authors' benchmarks or run new scientific experiments.

This repository contains only the static website. Local authoring files, intermediate audio/frames, workspace configuration and credentials are excluded. GitHub Pages publishes the root of the `codex/pages` branch. All assets use relative URLs, so the project path is supported without a bundler.

For offline reading, download the repository and open `offline.html` in a browser, preserving the sibling `media` and `sources` directories.
